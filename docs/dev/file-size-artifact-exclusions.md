# Generated and external size exclusions

These are explicit additions to the file-size policy, established while auditing
the whole repository in [#208](https://github.com/EnzoTironi/zoen-native/issues/208).
They are not exemptions for maintained source, tests, documents or patches.

| Exact outputs | Producer or provenance |
| --- | --- |
| `crates/miniapps/resources/{countdown,list,maptap,pet,poll,recipe}.html` | `tools/miniapp-build/build.mjs` emits HTML plus integrity manifests from the six authored entries and manifests in `miniapps/builtins/`; see its README. |
| `crates/miniapps/resources/{hike,schedule}.html` | The same builder emits the authored `miniapps/hike` and `miniapps/schedule` entries. |
| `crates/miniapps/resources/excalidraw.html` | `miniapps/excalidraw-ui/build.mjs` bundles the authored MCP entry and pinned dependencies; its `--check` verifies generated outputs. |
| `crates/miniapps/resources/deckcraft.html` | `miniapps/deckcraft-ui/build-bootstrap.mjs` bundles the authored bootstrap, SDK and dependencies; see `NATIVE-INTEGRATION.md`. |
| `apps/zoen/modules/zoen-core/ios/EmojiKeyboard/ZoenEmojiKeyboardData.swift` | `generate-telegram-emoji.py` in the same directory generates static Unicode data from the pinned `emoji1.txt`; its NOTICE and provenance describe the input and output. |
| `miniapps/excalidraw-ui/THIRD-PARTY-LICENSES.txt` | `build.mjs` aggregates dependency license texts and checks their exact generated bytes. |
| Root `LICENSE` and `LICENSES/GPL-3.0.txt` | Original Free Software Foundation AGPLv3/GPLv3 license texts, not authored program code. |
| `apps/zoen/modules/zoen-core/ios/EmojiKeyboard/emoji1.txt` | Original pinned Telegram Unicode catalog, described and hashed in `EmojiKeyboard/NOTICE.md` and `provenance.json`. |
| `apps/zoen/modules/zoen-core/ios/TelegramAttachmentPresentation/Resources/{TabPhoto,TabFile,TabAudio,TabLocation,TabPoll,Files}.json` | Original Telegram TGS animation values, decompressed without structural edits. Exact origins are in `UPSTREAM_ASSETS.json`; attribution and transformation are in the port's `NOTICE.md`. |
| Telegram GPL notice copies in `TelegramAttachmentPresentation`, `TelegramFileAttachment` and `TelegramVideoEditing` | Original GPLv3 text bundled with the respective upstream-derived integrations, under each directory's `Resources/Notices/`. |

The exact filenames are listed in `.githooks/pre-commit`. New filenames do not
inherit these exceptions. Authored builders, manifests, source views, native
adapters, patches and tests remain checked. The source policy does not replace
the existing runtime resource, integrity or media-size limits.

Do not split compiled bundles, Unicode catalogs or license texts into arbitrary
chunks just to satisfy a source-size rule. Do not mark maintained code as an
artifact. Additional upstream code needs its own provenance review; this list
does not exempt entire Telegram directories or their Zoen adapters.
