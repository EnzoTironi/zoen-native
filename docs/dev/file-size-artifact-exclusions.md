# Generated and external size exclusions

These are explicit additions to the file-size policy, established while auditing
the whole repository in [#208](https://github.com/EnzoTironi/zoen-native/issues/208).
They are not exemptions for maintained source, tests, documents or patches.

| ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `crates/miniapps/resources/{hike,schedule}.html`                                                                                      | The same builder emits the authored `miniapps/hike` and `miniapps/schedule` entries.                                                                                                      |

The generated Excalidraw manifest contains the resource hash/size and the audited
inventory (78 bundled dependencies and 36 source inputs in this release). Its
20,302 bytes are generated metadata, rather than authored editor code. The
builder, authored manifest neighbors and JSON documents remain subject to the
20,000-byte source limit; this exception names only that output.

The exact filenames are listed in `.githooks/pre-commit`. New filenames do not
inherit these exceptions. Authored builders, manifests, source views, native
adapters, patches and tests remain checked. The source policy does not replace
the existing runtime resource, integrity or media-size limits.

Do not split compiled bundles, Unicode catalogs or license texts into arbitrary
chunks just to satisfy a source-size rule. Do not mark maintained code as an
artifact. Additional upstream code needs its own provenance review; this list
does not exempt entire Telegram directories or their Zoen adapters.

## Byte-pinned upstream source

`miniapps/excalidraw-ui/src/sounds.ts` is the unmodified embedded-audio input from
[official commit 157aa23](https://github.com/excalidraw/excalidraw-mcp/blob/157aa23ceb1976008aadc89eb05e3444060f09d6/src/sounds.ts).
Its 55,492 bytes were compared directly with that official GitHub blob. SHA-256 is
`c197a890a699a9ed3348cc5ff12d676b2e9923ab25fcb80045cdad10f4baff4f`;
`upstream.json` pins it and the existing `build.mjs` verifies it before bundling.

This exception requires both the exact path and original staged Git blob ID
(SHA-1 or SHA-256 repository format). It does not exempt a local fork, a filename
alone or identical bytes copied into an authored neighbor. The hook and full
audit both check the index ID; an unstaged edit cannot change their decision.
No sound, App source, builder or compiled resource was modified for this review.

`apps/zoen/modules/zoen-core/ios/TelegramAttachmentPresentation/Resources/TabArticle.json`
is the original 43,092-byte animation obtained only by gzip decompression of
[Telegram's pinned TabArticle.tgs](https://github.com/TelegramMessenger/Telegram-iOS/blob/f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838/submodules/TelegramUI/Resources/Animations/TabArticle.tgs).
The actual pinned upstream download matches the retained TGS SHA-256
`933a88183e58c22527b409da0f254602a21159f67167796cb03cc1bcee8dc573`;
its decompressed bytes match the retained JSON SHA-256
`10cf5f370c2e367a5e60f98014674ca12adfe8d7c0c23644e3112f12f01fdc3e`.
`UPSTREAM_ASSETS.json` records the same origin, transform and hashes. Only that
exact path and staged Git blob receive the exception, in both Git object formats.
A local edit, same-name replacement or authored neighbor remains checked. The
animation and its runtime loader are unchanged.
