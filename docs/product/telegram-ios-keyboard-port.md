# Conversation composer and keyboard panels

Telegram-iOS revision `f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838` supplies the composer font/inset/slot geometry, glyphs, glass parameters, emoji order and compact grid metrics. Exact glyph provenance is in `apps/zoen/assets/telegram-composer/UPSTREAM.json`; emoji provenance and the reproducible generator are in `apps/zoen/modules/zoen-core/ios/EmojiKeyboard/`. Existing composer/audio source receipts remain in `telegram-ios-composer-audio-sources.json`.

The mounted React Native text field remains the only editor. Send occupies a46-point slot with a3-point solid-fill inset. The32-point input-mode control overlays the field; the text reserves the source clearance once. iOS26 controls share a7-point glass container. Older systems use the presentation fallback. Both shipped sky photographs are below the upstream saturation threshold in the recorded source analysis; custom sky colors currently retain the panel material. Day and Night remain the only shipped sky families.

The native keyboard host attaches a UIKit `UIInputView` to the exact mounted editor. Presentation tokens, React tags, field context and current first responder fence callbacks. It restores the previous input view and waits for native removal before handing off to camera, files or full media review. The existing Photos session retains permission, album, pagination and ordered-selection authority; the existing durable media draft retains caption, preparation and send authority. The native grid is a projection, not another library/draft store.

The emoji adapter inserts only pinned Unicode sequences through that editor's native `insertText`/`deleteBackward` operations. Categories, deletion, keyboard return and skin-tone variants work without importing a Telegram account or service. Recents are session-local. GIF, sticker catalog/search and remote media providers are not implemented by this panel. Variant artwork and the category strip are native Zoen adaptations, not a claim of exact Telegram raster equivalence.

The context-menu correction admits held selection only after vertical movement exceeds4points. A stationary release cannot select an action merely because the menu animated underneath the finger. Native tests and a Release build remain distinct from actual device interaction evidence; this source integration does not establish complete Telegram parity or whole-product acceptance.
