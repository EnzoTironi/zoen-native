# Próximo estudo de interface: Telegram iOS

Telegram iOS lidera a referência de interface e interações, conforme o
[guia](telegram-ios-reference.md). Esta tabela organiza cinco superfícies atuais;
não seleciona as 506 capacidades do [catálogo](../../output/telegram-feature-matrix-2026-10-20/index.html),
não acrescenta jornadas de aceitação e não altera código de produto.

Todos os links Telegram abaixo usam o commit
`f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838`. São pistas **por área**, importadas
do catálogo: a existência do arquivo foi registrada na pesquisa original, mas o
comportamento de cada feature ainda não foi rastreado. Antes de implementar,
estudar a interação completa, suas dependências e licença, e comparar com o
contrato atual do Zoen. A tabela não declara defeitos ou paridade nas superfícies.

A implementação segue os lotes existentes da [meta do produto](../dev/zoen-complete-product-goal.md).
Signal continua orientando confiabilidade, recuperação e testes comportamentais;
Notion/ChatGPT Spaces orientam documentos vivos e criação. Uma eventual adaptação
de fonte exige decisão própria de licença/dependências; este estudo não autoriza
TDLib, backend do Telegram, outra base de estado ou uma mudança de framework.
