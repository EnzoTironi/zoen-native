# Native presentation integration

This layer opens the registered DeckCraft resource through the existing fullscreen App route. It does not create another document database. The Rust binary document journal remains canonical, and the official MCP Apps protocol binds every read/write to the focused artifact and captured account/device/session.

## Rebuild the bootstrap

Use the repository's installed application dependencies. `node miniapps/deckcraft-ui/build-bootstrap.mjs` bundles the actual official Apps SDK and document client into the one resource `crates/miniapps/resources/deckcraft.html`. `--check` verifies all generated bytes and third-party notices. The builder refuses external JS imports and preserves the existing 8 MiB HTML limit. The generated source manifest records the exact input bytes and bundled dependency licenses.

After the separately pinned managed engine package is built and audited, generate a complete endpoint-specific registry manifest with:

```
node miniapps/deckcraft-ui/build-resource-manifest.mjs VERIFIED_RUNTIME_PACKAGE_JSON OUTPUT_JSON
```

The root build owner supplies that exact JSON through `ZOEN_DECKCRAFT_RESOURCE_MANIFEST_JSON`. No server URL is committed as a default. The endpoint-neutral registry remains unavailable without the verified runtime package.

## Ownership and close

The interaction cover remains until the real guest's initial canonical open reports readiness. Closing an unopened loader can abort immediately because manual input was never exposed. Once open, that fact is sticky: pending/error display labels cannot bypass final save. Ordinary close blocks further input, serializes behind existing background/export work, and waits for the official teardown ACK. A failed save keeps the original mounted Session available for retry/discard; it never silently reloads or replaces it. A final close admitted during a background flush prevents that operation from resuming input. Owner/access retirement closes authority synchronously, aborts raw asset fetches, disposes transfers/frame, and drains active native export work before session cleanup completes.

Catalog creation retains one idempotency token for the exact account epoch/chat/form intent across an ambiguous retry. Core registration owns the genuine empty native document seed and signed card creation. The UI does not ship or reconstruct a blank document itself.

## Native exports

`session.share(format)` first flushes the live editor, reads the exact accepted native head, then requests that version/SHA from the guest. The guest independently verifies the accepted source and local Session head. The native helper checks format, source head, bounded metadata, ordered 192 KiB chunks, total file length and incremental SHA-256 before presenting `expo-sharing`. It closes/deletes its private temporary file and releases the guest transfer on success, cancellation, malformed output and owner loss. No full export base64 string crosses the native bridge. The filename includes the selected accepted version.

Hosted DeckCraft's own Export menu dispatches PDF/PowerPoint intents through the standard artifact-scoped App server tool to `session.share`. The original standalone download services remain unchanged. The sealed e16c755d iPhone-simulator Release presented actual native PDF and PPTX share sheets for the unchanged accepted version1. Independent inspection confirmed the PDF signature and the PPTX ZIP CRC, required XML and one slide; cancellation removed both private temporary files. This does not qualify edited-document export, an external recipient send or full PDF rendering. Failed caption waits remain recorded separately from the observed native share and file checks.

## Remaining qualification

Node/TypeScript tests alone do not establish WKWebView load, real engine edit/save, native share UI or iOS memory behavior. The native evidence below qualifies only its exact source, artifact and observed operations.

The managed compact/theme/safe-content package consumes the host theme and safe-area/close-button bounds without shrinking the canvas. Compact dark mode and the native close corner were observed on the phone. Both landscape orientations restore to portrait, but the desktop status labels overlap in landscape. Whole landscape usability and every editor subpanel remain unaccepted.

## Managed geometry/export supplement

The fourth upstream patch consumes finite official host geometry through the same Session owner queue. It uses egui's real safe-area input while retaining the full viewport/canvas; the hosted title controls and dialog/palette bounds also avoid the exact native close corner. It leaves standalone layout/services unchanged. Hosted Export offers the genuinely supported PDF/PowerPoint intent before generating any browser download, and the official App server tool binds it to this artifact's native accepted-head share path. A single live intent prevents repeated menu taps from presenting duplicate share sheets.

The initial geometry acknowledgment precedes canonical open/manual input. Detected DOM/canvas/WebRunner startup failures retire the pending queue and refuse future requests. Fixed nonpayload classes distinguish resource fetch, module initialization, graphics/runner and canonical open in the native localized error surface. No document text, URL, key, shader or raw exception is sent there, and no global timeout/cap is added. A genuinely unopened error can retry by remounting a fresh owner/runtime; a stale callback checks the exact owner and sticky opened flag so it cannot replace an accepted editing Session.

A separate bootstrap typecheck is available at `apps/zoen/node_modules/.bin/tsc -p miniapps/deckcraft-ui/tsconfig.json`. The manual `managed-startup-browser.mjs` oracle requires actual final JS/WASM and the pinned synthetic empty seed; it qualifies queued missing-canvas rejection against a healthy actual engine control in a fresh owned headless process. It does not qualify WKWebView or native share UI.

The independent sixth portability patch removes unsupported OS process-ID calls from all WebAssembly targets. Browser-local recovery IDs mix the existing JS random/clock; WASI retains the standard clock. These non-authority local IDs do not replace authenticated canonical artifact identity. This patch is shared with the headless worker and does not require the browser geometry changes.

## Selected historical export

History resolves the chosen version through the authorized `app_binary_read` projection, then opens that exact version/SHA-256. The native session pins all reads and export-source requests to it, refuses all write-transfer tools, and exposes `readOnly` only on its trusted read response. The guest freezes the existing engine before reporting ready; resume/close cannot re-enable editing. Separate native PDF/PowerPoint actions remain usable while the upstream editor and its menus are frozen. Neither action restores the historical version or creates a new version.

Export revalidates the original canonical source and the rendered engine's accepted head. The pinned upstream ABI exports `accepted_doc`, never an unaccepted UI buffer. A changed/missing hash, retired frame/account/device, or lost conversation membership refuses the operation; there is no fallback to current. The ordinary current-document path still flushes its accepted save before choosing the export head.

Run the actual browser engine regression with an existing, audited JS/WASM pair and its original runtime manifest (no Cargo rebuild):

```
node miniapps/deckcraft-ui/test/history-export-browser.mjs \
  /absolute/existing-managed-dist /absolute/new-evidence-directory \
  /absolute/pinned-runtime-package.json
```

It uses the official App SDK and production session/document/stream-export adapters with a synthetic Core read port. It advances current from v1 to v2, verifies frozen v1/hash, rejects a real WASM edit, creates real PDF/PPTX bytes, and checks retirement and zero native saves. This is browser ABI/host evidence, not Rust authorization, WKWebView, iPhone history/share, or complete #174 acceptance. Existing worker/WASM qualification and pins remain unchanged.
