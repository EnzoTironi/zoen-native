# Sky footage credits

The docs site's living sky uses four short looping clips cut from free-licence time-lapse videos on
Wikimedia Commons. Each clip was trimmed to 8 seconds, crossfaded end-to-start so it loops without a
jump, scaled to 960×540, re-encoded (WebM/VP9 and MP4/H.264, no audio) and given a JPEG poster.
The files are in `docs-site/public/sky/`. The site also blurs and tones them, so they appear softened.
